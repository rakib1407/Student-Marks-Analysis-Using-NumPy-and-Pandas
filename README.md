Project Title

Student Marks Analysis Using NumPy and Pandas

Project Description

This project analyzes the academic performance of students using a dataset that includes marks in Math, Reading, and Writing. The main objective is to extract meaningful insights from the dataset, identify trends, and evaluate student performance using Python libraries NumPy and Pandas.

Key Objectives
Calculate Total and Average Marks
Sum up marks across all subjects for each student.
Calculate the average marks for overall performance evaluation.
Pass/Fail Determination
Students with an average of 50 or higher are considered to have passed.
Helps identify students who need additional support.
Identify Top and Bottom Scorers
Determine the highest and lowest performing students based on total marks.
Subject-wise Analysis
Calculate average marks for each subject.
Analyze which subjects students perform best or worst in.
Gender-wise Analysis
Compare average marks and pass rates between male and female students.
Test Preparation Course Analysis
Compare performance of students who completed test preparation versus those who did not.
Correlation Analysis
Study relationships between different subjects to understand performance patterns.
Tools and Libraries
Python – Programming language
NumPy – For numerical operations and calculations
Pandas – For data manipulation, aggregation, and analysis
